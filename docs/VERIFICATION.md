# 验证记录

## 现场行为证据

使用 HA 实时 API 及海尔设备状态推送完成对照，不依赖历史恢复文件。

1. 用户在海尔智家 App 操作智能温水、速热增容和变速档位。
2. 确认温水模式时 `heatKeepingStatus=true`，`heatingMode` 和 `power` 为空。
3. 确认增容模式时 `heatKeepingStatus=false`、`heatingMode=3`；功率为空。
4. 确认普通加热时 `power` 为档位代码，温水关闭、加热模式为空。
5. 用真实 HA 控件验证温水开启与关闭、增容开启与关闭、低中高档选择。
6. 所有操作均收到设备回报，测试结束恢复当时的原模式。
7. 最终仪表盘实时配置引用的三个实体状态均明确，配置检查无错误、无警告。

不同模式下能力位变化是关键：它不能被理解为永久不支持。以当前值为空为理由伪造高档状态，同样会误导用户。

## 仓库范例验证

- 配置示例使用占位实体，并未直接装入现场家庭配置。
- 模板配置按现场 HA Core 2026.6.3 的 `SWITCH_YAML_SCHEMA` / `SELECT_YAML_SCHEMA` 校验。
- 离线测试覆盖互斥模式、原生功率选项映射、无功率值及离线场景。
- 布局检查保证每行按 `6+6` 或 `12` 占满，使用原生卡片。
- 自动扫描及人工复核覆盖实际发布文件，不上传原始数据、认证代码和截图。

目标温度会随设备模式变化。测试结论不承诺其他型号也使用相同选项或有相同的切换结果。
